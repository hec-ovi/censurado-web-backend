# Admin UI Contract

- Scope: admin UI lives in `internal/adminweb`; server-rendered login is in `login.go`, SPA assets are in `static/`.
- Shared chrome: `/brand.css` owns the El Censurado Web wordmark and public-site theme tokens; `/controls.css` owns the fixed theme controls used by both login and SPA.
- SPA shell: `static/app.js` renders one full-width `app-topbar` that contains logo, separator, page title, and theme controls; keep the sidebar logo-free and flush under the header with no top label/gap so header alignment stays unified.
- Language: the panel is single-language English. `components/i18n.js` `t(key)` resolves the key against a catalog the server injects into the `#panel-i18n` data block (panel_text strings + shared `frontend_text` section labels via `SectionLabelsFromFrontend`), falling back to the English key so an unseeded catalog still renders. There is no language switch. Seed the catalog with `cmd/censurado/seedpanel`; operators edit copy via `POST /panel-text`. Section pickers show labels via `sectionLabelFor(slug)`, one source of record shared with the site.
- Login assets: `/login` loads shared `/brand.css`, `/controls.css`, `/styles.css`, isolated `/login.css`, and `/login.js`; keep login-only styling out of the main stylesheet.
- Articles list: `components/articlesPanel.js` is a list-only table, not cards. It reads `/articles:days`, `/articles`, `/authors`, and `/portadas`: normal browsing first loads a date index and then one selected date page from `/articles`, while the title/subtitle article search runs on Enter across all dates with `title_subtitle_q`. Media filters use the API `card_type` (text/image/youtube/video mapped to youtube), and video cards must preview from `metadata.card.src` or `metadata.video` instead of showing a separate Video tag. Portadas provide per-day position + single/full/main span role, and authors provide face/name display. Filters are client-side Show checkboxes, Date order radios, searchable day dropdown, title/subtitle article search, and searchable author dropdown; date order arranges day pages, while article order inside a day stays portada order. Rows open by row click and delete through an internal confirmation dialog. `static/articles.css` owns list/table/delete-modal styles.
- Automation: `components/automationPanel.js` is the batch-run schedule manager over `/schedules` (list + full-upsert editor dialog + two-click delete) with a recent-runs strip fed by the server-owned `runs` field. Clock math (next fire time, cadence day matching, draft validation) lives in `static/schedule.js` as pure functions the executor's semantics mirror. `components/modelsSection.js` is the tab's Models section over `/automation-settings`: model lanes (local llama.cpp, OpenRouter) and per-stage routing, saved wholesale, blanks meaning "pipeline file default"; the OpenRouter key never passes through the panel (it lives in the stack's `.env`). `static/automation.css` owns the tab's chrome (time chips, day grids, run strip, models cards).
- Theme: admin theme is `localStorage["panel-theme"]`; both login and SPA honor it. There is no locale storage (the panel is English-only).
- Brand: `.admin-wordmark` mirrors `censurado-web/internal/generate/templates/components/chrome.tmpl`; change wordmark styling in `static/brand.css` so login and SPA move together.
- Local stack: active admin URL is `http://127.0.0.1:8082/login`; rebuild with the `censurado-web-brain` Compose `publish` service after embedded asset changes.
